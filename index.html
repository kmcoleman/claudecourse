5-Day Bootcamp · Intent-Based Development

Claude Certified Architect

Five days building one real agentic system — an automated user-access review for a regional utility — from a plain CLAUDE.md up to a self-checking orchestrator that generalizes to data it has never seen.

The outcome

You understand the building blocks of an agentic system — and can build one yourself using intent-based development: you describe what good looks like, and direct Claude Code to build it.

↳Before you arrive

Day 1 assumes your laptop is already set up. Complete the pre-work in the three weeks before class so the bootcamp is about building, not troubleshooting — and take the quick skill survey so the week can be paced for the people actually in the room.

Do this first · 4–6 hours over 3 weeks

Pre-Work module

Six short cycles: install your dev environment, get GitHub Enterprise access working, set up Claude Code, clone the kit, and run the smoke test green. Fully ready for Day 1.

02The arc — six building blocks

Six parts, assembled in order. Rules give Claude its standing instructions, skills give it the rulebook, tools give it reach, subagents divide the labor, hooks keep it honest, and generalization proves it holds. Each block below is marked with the sub-task where you finish it — the milestone, not the introduction.

  1. 1
    Rules CLAUDE.md

    How you tell Claude Code to behave. Project rules that load every session and shape every response — the standing instructions the whole system sits on.

    Completed at sub-task 7 5-day pacing: Day 1 ↗
  2. 2
    Skills policies/*.md

    Markdown policies Claude applies on demand. Meridian's five written compliance policies become Agent Skills the reviewer reaches for when a case calls for them.

    Completed at sub-task 17 · starts at 16 5-day pacing: Day 3 ↗
  3. 3
    Tools MCP server

    The agent's senses and hands. Read-only lookups let Claude ask about one account, person, or ticket at judgment time — targeted questions, not bulk data.

    Completed at sub-task 20 5-day pacing: Day 4 ↗
  4. 4
    Subagents orchestrator + specialists

    One orchestrator directing many specialists. Split the review into focused agents that each own a single kind of judgment, then gather their findings.

    Completed at sub-task 23 5-day pacing: Day 4 ↗
  5. 5
    Hooks .claude/hooks/

    The enforcement and audit layer. Deterministic guards run before a tool fires; an audit trail records what happened after — the parts you don't leave to judgment.

    Completed at sub-task 26 5-day pacing: Day 4 ↗
  6. 6
    Generalization 2026-Q4

    Pattern transfer to unseen data. Point the finished system at a new quarter and prove it holds — same shape, different specifics. This is the certification.

    Completed at sub-task 39 5-day pacing: Day 5 ↗
